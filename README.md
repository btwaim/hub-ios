# Hub für iPhone

Persönliche iPhone-App zu meinem Hub (Desktop-App): Musik offline im Hub-Sound, mitlaufende Lyrics und Wecker nach Stundenplan.

- Gebaut wird automatisch auf GitHub Actions (macOS 26, Xcode 26), ohne Signatur. Jeder Build landet als `Hub.ipa` unter *Releases*.
- Installation per AltStore (kostenlose Apple-ID).
- Verbindung zum Hub per QR-Code (`hubapp://setup?...`); Adresse und Schlüssel stehen nicht im Code.
